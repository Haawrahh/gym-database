Reflection
Why I chose these entities,
I chose entities like Members, Trainers, Classes, Bookings and Invoices because they represent a normal gym system. These entities make it possible to handle memberships, class bookings and payments in a simple and clear way.

Normalization,
I tried to normalize the database by separating data into different tables. This helps avoid duplicated information and makes the database easier to maintain.

Constraints that protect the data,
Primary keys and foreign keys are used to connect the tables correctly.
NOT NULL and UNIQUE constraints are used where needed to make sure the data is valid.

What I would improve next,
Next step would be to add views and stored procedures to make queries easier. I would also improve security and add more validation.
